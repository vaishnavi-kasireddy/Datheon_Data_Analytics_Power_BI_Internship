# Datheon Data Analytics & Power BI Internship

Two projects using the Superstore retail sales dataset from 2015 to 2018. Task 1 explores the data in Python. Task 2 turns the analysis into an interactive Power BI report.

## Task 1 — Superstore Sales Exploratory Data Analysis

I used Python and Pandas to separate 806 non-sales records from the source file, leaving 9,994 sales line items. I analysed monthly sales, regional performance, customer segments, and how discounts were associated with profit margins.

[View the Task 1 notebook, charts, and setup instructions](./Task_1_Superstore_EDA/)

## Task 2 — Power BI Executive Sales Dashboard

I cleaned the data in Power Query, built a star schema, and created DAX measures for sales, profit, profit margin, distinct orders, and year-over-year sales growth. The two-page report shows overall performance and lets readers explore which products made or lost money.

[View the Task 2 dashboard and PDF](./Task_2_PowerBI_Dashboard/)
