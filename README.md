\# Datheon Data Analytics \& Power BI Internship



I completed two projects using the same Superstore retail sales dataset from 2015 to 2018. In Task 1, I used Python to clean and analyse the data. In Task 2, I built a Power BI report so readers could explore the results by date, region, and product category.



\## \[Task 1 — Superstore Sales Exploratory Data Analysis](./Task\_1\_Superstore\_EDA/)



I used Pandas to separate 806 non-sales records from the CSV, leaving 9,994 sales line items. I then analysed monthly sales, regional performance, customer segments, and how discounts were associated with profitability.



The folder includes the Jupyter notebook, seven charts, and a task-specific README with setup instructions.



\## \[Task 2 — Power BI Executive Sales Dashboard](./Task\_2\_PowerBI\_Dashboard/)



I cleaned the source data in Power Query, built a star schema, and created DAX measures for sales, profit, profit margin, distinct orders, and year-over-year sales growth.



The report has two pages:



\- \*\*Executive Overview\*\* — KPI cards, monthly sales, regional sales, and annual growth.

\- \*\*Product Profitability\*\* — a product treemap and a matrix comparing sales, profit, and margin by category and sub-category.



The folder includes the interactive `.pbix` report and a two-page PDF preview. Open the `.pbix` in Power BI Desktop to use the date and region filters.



\## Key findings



\- Superstore recorded \*\*2,297,200.86 in sales\*\* and \*\*286,397.02 in profit\*\* across \*\*5,009 distinct orders\*\*, for a \*\*12.47% profit margin\*\*.

\- Furniture generated \*\*741,999.80 in sales\*\* but had a margin of only \*\*2.49%\*\*. Within Furniture, Tables recorded a \*\*17,725.48 loss\*\*.

\- Sales grew \*\*20.36% in 2018\*\* compared with 2017.
